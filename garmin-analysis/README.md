# Garmin デイリーレポート

Garmin Connect のデータ(睡眠・安静時心拍・ボディバッテリー・ストレス・歩数・体重・アクティビティ)を
自動で取得し、1枚のHTMLレポートにまとめるスクリプトです。

内部的には [Taxuspt/garmin_mcp](https://github.com/Taxuspt/garmin_mcp) と同じ
`garminconnect` / `garth` ライブラリを使って Garmin Connect にログインします
(garmin_mcp 自体はMCPサーバーですが、このスクリプトは同じ土台をシンプルなCLIとして
直接使っています)。

## セットアップ

```bash
cd garmin-analysis
pip install -r requirements.txt
```

> **重要: このスクリプトはあなたのPC(自宅回線)で実行することを想定しています。**
> Garmin ConnectはCloudflareのボット対策でクラウド/データセンターのIPアドレスからの
> ログインを403/429でブロックすることが多く、Claude Code on the webのようなクラウド実行環境
> からは自動ログインできない場合があります(実際にこのリポジトリで確認済み)。これは
> Garmin側の意図的なブロックのため、回避策(TLSフィンガープリント偽装やプロキシなど)を
> 追加で講じることは行いません。素直にご自宅のネット回線から実行してください。

### 認証情報

**パスワードをコードやリポジトリに書かない・コミットしないでください。**

このフォルダに `.env` というファイルを作り、そこにログイン情報を書くのが一番簡単です
(`.env` は `.gitignore` で除外済みなので、間違ってコミットされません)。

```bash
cd garmin-analysis
cp .env.example .env
# .env をエディタで開いて GARMIN_EMAIL / GARMIN_PASSWORD を実際の値に書き換える
```

`.env` の代わりに、OSの環境変数として渡すこともできます:

| 変数 | 説明 |
|---|---|
| `GARMIN_EMAIL` | Garmin Connectのログインメールアドレス |
| `GARMIN_PASSWORD` | Garmin Connectのパスワード |
| `GARMIN_TOKENSTORE` | (任意) ログインセッションのキャッシュ先。省略時は `~/.garmin_tokens` |
| `GARMIN_MFA_CODE` | (任意) 2段階認証が有効な場合の6桁コード。対話実行時は未設定でも入力を求められます |

> Googleアカウントでログインしている場合は、Garmin Connectのログイン画面から
> 「パスワードをお忘れですか?」でGoogleログインと同じメールアドレス宛にパスワードを
> 再設定してください。それによって発行される「メール+パスワード」でこのスクリプトは
> ログインできます(Googleログインは引き続き使えます)。

### 初回ログインと2段階認証について

- アカウントに2段階認証(MFA)が**設定されていない**場合、`GARMIN_EMAIL` /
  `GARMIN_PASSWORD` だけで毎回自動ログインできます。
- **設定されている**場合、自動実行中にMFAコードを入力することはできません。
  最初の1回はターミナルなどで対話的に実行してコードを入力し、ログインセッションを
  `GARMIN_TOKENSTORE`(既定 `~/.garmin_tokens`)にキャッシュしてください。
  以降はそのキャッシュが再利用され、MFAなしでログインできます(ただし、このリポジトリを
  クローンし直す/コンテナを作り直す実行環境では、このキャッシュはローカルディスクにしか
  残らないため、コンテナが作り直されるたびに再度MFAが必要になる場合があります)。

## 使い方

```bash
python3 garmin_report.py                     # 直近14日間のトレンド + 直近7日間のアクティビティ
python3 garmin_report.py --days 30            # トレンド期間を30日に
python3 garmin_report.py --activity-days 14   # アクティビティ一覧を14日分に
python3 garmin_report.py --out /tmp/report.html
```

実行すると:

- `reports/<YYYY-MM-DD>.html` … その日付のレポート(日次アーカイブ)
- `reports/latest.html` … 最新レポート(常に上書き)

が生成されます。`reports/` ディレクトリはレポート本体(個人の健康データ)を含むため
`.gitignore` でリポジトリへのコミット対象から除外しています。

## 取得しているデータ

- **睡眠**: 睡眠スコア、睡眠時間、深い睡眠/レム睡眠の内訳
- **心拍・ボディバッテリー・ストレス**: 安静時心拍、ボディバッテリーの充電量、平均ストレスレベル
- **歩数・体重**: 日次の歩数、体組成計で計測した体重(データがある日のみ)
- **アクティビティ**: 種目・距離・時間・ペース・平均心拍・消費カロリー

デバイスやアカウントの設定によっては取得できない項目もあり、その場合はレポート上に
「データなし」と表示されます(エラーにはなりません)。

## 自動化(毎日のレポート生成)

自宅PCで、OS標準のスケジューラから毎日決まった時間に実行させます。

### macOS / Linux (cron)

```bash
crontab -e
```

を開き、以下の行を追加(毎朝7:00に実行する例。パスは自分の環境に合わせて書き換えてください):

```
0 7 * * * cd /path/to/timer/garmin-analysis && /usr/bin/python3 garmin_report.py >> report.log 2>&1
```

### Windows (タスクスケジューラ)

1. 「タスクスケジューラ」を開き、「基本タスクの作成」
2. トリガー: 毎日、実行したい時刻を指定
3. 操作: 「プログラムの開始」→ プログラム/スクリプトに `python`、引数に
   `garmin_report.py`、開始(作業フォルダ)に `garmin-analysis` フォルダのパスを指定

### レポートの確認

`reports/latest.html` が毎回上書きされるので、ブラウザでそのファイルを開けば
最新のレポートが見られます。過去分は `reports/<日付>.html` に残ります。

### Claude Codeで見たい場合

ローカルで生成した `reports/latest.html` の中身をClaude Codeのセッション
(このリポジトリを開いているセッション)に貼り付ける・アップロードすれば、
その内容についてChatで質問したり、傾向を解説してもらったりできます。
ただし、Garmin Connectへのログイン自体は上記の理由によりPC側で行ってください。
